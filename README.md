# Enterprise HR Management Platform

Full stack project scaffold generated in Phase 1 (Planning) of our mentorship project.

## Structure

- `hr-platform-backend/`  — Node.js + Express + PostgreSQL + Prisma REST API
- `hr-platform-frontend/` — React + Tailwind CSS client

## Status

This is an empty scaffold: folders and files exist with explanatory comments only.
Real implementation begins in Phase 2 (Backend Development).

## Roles

- Admin — manages departments, HR accounts, audit logs
- HR — manages employees, salary, leave, attendance, documents
- Employee — views own profile, submits leave, checks attendance

See the mentorship conversation for the full Phase 1 planning (business problem,
requirements, architecture, database design, folder structure rationale).
